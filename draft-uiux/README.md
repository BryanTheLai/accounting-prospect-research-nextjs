# OpenClose UI/UX drafts

Ten complete HTML app directions on `redesign/nextjs-drafts`.

Open [index.html](index.html) to browse and shortlist. Star two directions to compare side by side. Every draft has live navigation, prospect search and filtering, record selection, CSV export, campaign draft creation, and browser-local settings controls. The prototype uses fictional records; it sends no messages.

| # | Direction | Design idea |
|---:|---|---|
| 01 | [Paper ledger](01-paper-ledger.html) | Paper, precise rules, and Stackifier’s sharp lime accent. |
| 02 | [Night shift](02-night-shift.html) | Low-glare charcoal with quiet, readable states. |
| 03 | [Open book](03-open-book.html) | Editorial type and book-like columns. |
| 04 | [Field station](04-field-station.html) | A compact rail and broad, fast working canvas. |
| 05 | [The register](05-the-register.html) | An orderly register built around the next action. |
| 06 | [After hours](06-after-hours.html) | Warm dark surfaces and one clear action per screen. |
| 07 | [Blue room](07-blue-room.html) | Measured blue-gray navigation with paper evidence. |
| 08 | [Counterbook](08-counterbook.html) | Parchment and oxblood, drawn from an accountant’s ledger. |
| 09 | [Quiet grid](09-quiet-grid.html) | Almost no ornament; alignment does the work. |
| 10 | [The dossier](10-the-dossier.html) | A persistent context pane beside the selected prospect. |
